# Комната 863

Короткая браузерная хоррор-игра от первого лица на **Three.js**. Три связанных уровня, скримеры, преследование монстром и побег — всё в одном статичном сайте без сборки, серверов и зависимостей из npm.

```
меню → уровень 1 (комната) → уровень 2 (подвал и лифт) → уровень 3 (серверная, финал)
```

## Как играть

**Компьютер**

| Клавиша | Действие |
|---|---|
| `W` `A` `S` `D` | движение |
| Мышь | обзор |
| `Shift` (уровень 3) | бег |
| `E` | взаимодействие (двери, ноутбук, фонарик, рубильник, генераторы) |
| `Esc` | пауза (освобождает курсор), клик по экрану — продолжить |

**Телефон и планшет** — управление включается автоматически:

- левая половина экрана — джойстик движения (сильное отклонение = бег на 3 уровне);
- правая половина — свайп для обзора;
- кнопка `E` справа внизу — действие;
- кнопка `II` справа вверху — выход в меню.

Проверить сенсорное управление на компьютере можно, открыв `index.html?touch=1` (`?touch=0` — принудительно выключить).

## Запуск

Игра — обычные статические файлы. Достаточно открыть `index.html` в браузере.

Если браузер ограничивает загрузку файлов с диска (бывает в Chrome), поднимите локальный сервер в папке проекта:

```bash
python -m http.server 8000
# затем откройте http://localhost:8000
```

Публикация одной кнопкой: **Settings → Pages → Deploy from branch → main / root** — игра заработает по адресу вида `https://<ник>.github.io/The-laptop/`.

## Тесты

В репозитории есть автотесты на [jsdom](https://github.com/jsdom/jsdom) с заглушкой three.js: они поднимают локальный сервер, открывают все страницы как браузер и проверяют громкость, прогресс, звук двери, запуск уровней, сенсорное управление и игровую логику (дверь, ноутбук, рубильник, генераторы, смерть от монстра) — 71 проверка.

```bash
npm install     # единственная dev-зависимость — jsdom
npm test
```

## Настройки и прогресс

Меню хранит состояние в `localStorage` браузера:

- **громкость** — общий множитель для всех звуков игры (ползунок в «Настройках»);
- **прогресс** — максимальный открытый уровень, из меню появляется кнопка «Продолжить — уровень N»;
- **сброс прогресса** — кнопка в «Настройках».

## Структура проекта

```
index.html            меню: старт, продолжить, настройки, выход
one.html              уровень 1 — комната 863: фонарик и код на стене
two.html              уровень 2 — подвал: рубильник, лифт, монстр
three.html            уровень 3 — серверная: генераторы и побег (финал)
js/room863.js         общее: громкость, прогресс, переходы, проверка three.js/WebGL
js/touch.js           сенсорное управление (джойстик, обзор, кнопки E и «в меню»)
vendor/three.min.js   three.js r128 локально — игра работает без интернета
tests/                автотесты (jsdom + заглушка three.js)
package.json          только для тестов: npm install && npm test
image/face.jpg        лицо монстра (текстура, скример)
music/*.mp3           фон, крик, стук, двери
```

### Как связаны уровни

Каждый уровень — самостоятельная страница со своим скриптом; общее лежит в `js/room863.js`.
Для сенсорного управления уровень объявляет мост `window.R863Input` (`begin`, `move`, `look`, `interact`, `setSprint`) — им пользуется `js/touch.js`. Если моста нет, игра просто остаётся клавиатурной.

## Технологии

- [Three.js](https://threejs.org/) r128 — WebGL-рендер (`vendor/three.min.js`, лицензия MIT — `vendor/three.LICENSE.txt`);
- чистый JavaScript и CSS без фреймворков и сборки;
- HTML5 Audio для звука, Canvas — для процедурных текстур (код на стене, табличка 863).

## Известные особенности

- `face.jpg` — стилизованное изображение; при желании его легко заменить своим (те же пропорции, путь `image/face.jpg`).
- Тени включены при почти полной темноте: на слабых устройствах можно отключить `renderer.shadowMap.enabled` в уровне.
- Звук в браузере стартует только после первого клика/касания — так требует политика автовоспроизведения.
